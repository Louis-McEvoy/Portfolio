# Louis McEvoy portfolio site

Static site. Open `index.html` in a browser, or serve the folder (`python3 -m http.server`) and visit http://localhost:8000.
Host anywhere that serves static files (GitHub Pages, Netlify, Vercel) by uploading this folder as is.

- `index.html` home; `work/*.html` seven case studies
- `assets/site.css`, `assets/site.js` all styling and behaviour (no frameworks, no trackers, no external requests)
- `assets/fonts` Inter Tight and JetBrains Mono (SIL Open Font License), self-hosted
- `assets/img` WebP images extracted from your portfolio PDFs and robotics coursework
- `DESIGN.md` the design spec (colours, type, layout, motion)
